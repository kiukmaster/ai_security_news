# Workflow Rules

Before starting:
1. Read CLAUDE.md or AGENTS.md.
2. Read every file in harness/.
3. Understand the current project structure.
4. Do not edit files immediately.

Before editing:
1. Explain the problem.
2. Identify the files that need changes.
3. Explain the planned change briefly.

During editing:
1. Make the smallest possible change.
2. Do not change unrelated files.
3. Preserve existing behavior unless asked.

After editing:
1. Run available tests if possible.
2. If tests cannot be run, explain why.
3. Summarize changed files and results.
