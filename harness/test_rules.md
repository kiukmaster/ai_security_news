# Test Rules

When code is changed:
1. Run existing tests if available.
2. If no tests exist, suggest simple test cases.
3. For bug fixes, explain how to reproduce the bug.
4. For new features, explain how to verify the feature.

Do not claim that tests passed unless they were actually run.

- Tests run:
- Result:
- If not run, reason:
- Please summarize it clearly and concisely, making it easy to read.
